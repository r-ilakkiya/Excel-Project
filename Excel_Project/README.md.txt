# 📊 Excel Customer Analytics Project

## 📌 Project Overview

This project focuses on **Customer Analytics using Microsoft Excel**. The main objective is to analyze customer information, purchasing behaviour, spending patterns, satisfaction levels, and membership types to understand customer trends and business performance.

This project demonstrates how Microsoft Excel can be used to organize data, perform calculations, analyze customer behaviour, and generate meaningful business insights.

## 🎯 Project Objectives

The project covers seven major areas of analysis:

### 1. 👥 Customer Demographics Analysis
- Customer count by gender.
- Customer count by membership type.
- Customer count by city.
- Average age by gender.
- Average age by membership type.

### 2. 💰 Revenue & Spending Analysis
- Average spending by gender.
- Average spending by membership type.
- Average spending by city.
- Total revenue by membership type.
- Total revenue by city.
- Revenue by gender and membership type.
- Average spending by gender and membership type.

### 3. 🛒 Purchase Behaviour Analysis
- Average items purchased by membership type.
- Average items purchased by gender.
- Average days since last purchase by membership type.
- Average days since last purchase by city.

### 4. ⭐ Customer Rating Analysis
- Average rating by membership type.
- Average rating by city.
- Average rating by city and membership type.

### 5. 😊 Customer Satisfaction Analysis
- Customer count by satisfaction level.
- Average spending by satisfaction level.
- Average rating by satisfaction level.
- Average items purchased by satisfaction level.
- Total spending by satisfaction level and membership type.

### 6. 🏷️ Discount Impact Analysis
- Customer count with and without discounts.
- Average spending with and without discounts.
- Average ratings with and without discounts.
- Average items purchased with and without discounts.

### 7. 📈 Combined Business Analysis
- Customer count by city and membership type.
- Customer count, total revenue, average spending, and average rating by membership.

## 📂 Dataset Description

The dataset contains **350 customer records** and includes the following columns:

| Column Name | Description |
|---|---|
| Customer ID | Unique customer identification |
| Gender | Customer gender |
| Age | Customer age |
| City | Customer location |
| Membership Type | Gold, Silver, or Bronze |
| Total Spend | Total amount spent |
| Items Purchased | Number of items purchased |
| Average Rating | Customer rating |
| Discount Applied | Whether a discount was applied |
| Days Since Last Purchase | Number of days since the last purchase |
| Satisfaction Level | Customer satisfaction category |
